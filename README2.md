## Description
This project contains **five Python practice tasks** that demonstrate basic concepts of:
- Lists
- Tuples
- Dictionaries
- Sets
- List Comprehension

---

## Tasks

### Task 1: List and Sum
- Accepts user input to create a list of integers.
- Computes and prints the sum of all integers.

### Task 2: Tuple of Books
- Creates a tuple containing 5 favorite books.
- Prints each book on a separate line.

### Task 3: Dictionary of Person Info
- Uses a dictionary to store user’s **name, age, and favorite color**.
- Accepts input from user and prints the dictionary.

### Task 4: Sets and Common Elements
- Accepts two sets of integers from the user.
- Creates a new set containing only the **common elements**.

### Task 5: List Comprehension
- Stores a list of words.
- Uses **list comprehension** to filter words with an **odd number of characters**.
