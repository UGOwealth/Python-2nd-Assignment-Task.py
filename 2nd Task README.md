# Task Instructions

This program demonstrates different list operations in Python:

Create an empty list called my_list.

Append the following elements: 10, 20, 30, 40.

Insert the value 15 at the second position in the list.

Extend the list with another list: [50, 60, 70].

Remove the last element from the list.

Sort the list in ascending order.

Find and print the index of the value 30.


## Overview
This assignment demonstrates common Python list operations such as:
- Creating a list
- Appending and inserting elements
- Extending with another list
- Removing elements
- Sorting
- Finding the index of a value

### Task Description
This assignment demonstrates basic operations on Python lists. The tasks involve creating a list, modifying it by inserting and appending elements, extending it with another list, removing items, sorting the list, and finally retrieving the index of a specific element.
